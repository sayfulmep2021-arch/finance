# 📱 Personal Finance | ব্যক্তিগত ও পারিবারিক হিসাব (PWA)

একটি আধুনিক, প্রিমিয়াম মোবাইল-ফার্স্ট **Progressive Web App (PWA)** — যা ব্যক্তিগত ও পারিবারিক আর্থিক হিসাব, আয়-ব্যয়, ধার-দেনা (ঋণ), বাজেট এবং সঞ্চয়ের লক্ষ্য ট্র্যাকিংয়ের জন্য সম্পূর্ণ অফলাইনে কাজ করে।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features)

1. **হুবহু প্রিমিয়াম মোবাইল ইন্টারফেস**:
   - **মেইন ওয়ালেট কার্ড**: বর্তমান স্থিতি (যেমন: ৳২,১৪৬), মোট আয় (+৳১৯,০৩২), মোট ব্যয় (-৳১৪,৬৬৮) এবং আকর্ষণীয় সাইকেল প্রগ্রেস রিং (খরচ হয়েছে ৯৮%)।
   - **মাল্টি-ওয়ালেট সাপোর্ট**: EBL ব্যাংক, bKash, নগদ, ক্যাশ ওয়ালেট এবং ওয়ালেট-টু-ওয়ালেট ট্রান্সফার।
   - **আয়-ব্যয় টগল**: এক ক্লিকে "আয়" এবং "ব্যয়" এর মধ্যে ফিল্টারিং।
   - **আইকনসহ সাম্প্রতিক ব্যয়**: বন্ধুদের সাথে চা (৳১৬০), মাছ (৳১,৫০০), শ্যাম্পু (৳৪০), Google AI Pro (৳২৫০) সহ যাবতীয় ক্যাটাগরি।
   - **ফ্লোটিং অ্যাকশন বাটন (FAB)**: নিচের ডান পাশে ভাসমান `+` বাটন দিয়ে যেকোনো লেনদেন, ধার বা ট্রান্সফার দ্রুত যোগ করা।
   - **৫টি বটম ট্যাব**: হোম, হিসাব, ঋণ, বাজেট ও পরিসংখ্যান।

2. **সম্পূর্ণ অফলাইন সুবিধা (Offline-First)**:
   - ব্রাউজারের **IndexedDB** (Dexie.js) এর মাধ্যমে সকল তথ্য সুরক্ষিতভাবে ডিভাইসের মেমরিতে সংরক্ষিত থাকে।
   - কোনো ইন্টারনেট সংযোগ ছাড়াই নতুন হিসাব যোগ, সম্পাদনা ও রিপোর্ট দেখা যায়।
   - কোনো বাহ্যিক ডাটাবেজ বা পেইড সার্ভারের প্রয়োজন নেই।

3. **ধার ও ঋণ খতিয়ান (Lending & Borrowing)**:
   - ধার দিয়েছি (পাওনা - Receivable) এবং ধার নিয়েছি (দেনা - Payable) এর নির্ভুল হিসাব।
   - কিস্তিতে আংশিক পরিশোধ (Partial Repayments) এবং সম্পূর্ণ নিষ্পত্তি।
   - হিসাবের মূলনীতি: ধার দেওয়া কোনো সাধারণ খরচ নয় এবং ধার নেওয়া কোনো আয় নয় — ফলে ডাবল কাউন্টিংয়ের ঝুঁকি নেই।

4. **বাজেট ও অ্যালার্ট সিস্টেম**:
   - মাসিক ব্যয়ের সীমা নির্ধারণ ও ক্যাটাগরিভিত্তিক বাজেট।
   - ৮০% ও ১০০% অতিক্রম করলে স্বয়ংক্রিয় সতর্কবার্তা।

5. **ডাটা ব্যাকআপ ও রিস্টোর**:
   - সম্পূর্ণ তথ্যের **JSON ব্যাকআপ** ডাউনলোড ও রিস্টোর সুবিধা।
   - এক্সেল বা গুগল শিটসে দেখার জন্য **CSV এক্সপোর্ট**।

6. **ক্রোম থেকে সরাসরি ইনস্টলেশন**:
   - আলাদা Android APK তৈরি বা ম্যানুয়াল ইনস্টলেশনের ঝামেলা নেই। GitHub Pages লিংক থেকেই সরাসরি ইনস্টলযোগ্য।

## 🚀 লোকাল কম্পিউটারে রান করার নিয়ম (Local Development)

## 🌐 GitHub Pages-এ ডিপ্লয়মেন্ট করার নিয়ম (Automated GitHub Deployment)

প্রজেক্টে `.github/workflows/deploy.yml` কনফিগার করা আছে। GitHub-এ কোড পুশ করার পর ডিপ্লয়মেন্ট সম্পন্ন করতে নিচের ধাপগুলো অনুসরণ করুন:

1. **GitHub-এ নতুন রিপোজিটরি তৈরি করুন**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Personal Finance PWA"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

2. **GitHub Pages সেটিংসে সোর্স পরিবর্তন করুন**:
   - আপনার GitHub রিপোজিটরির **Settings** ট্যাবে যান।
   - বাম পাশের মেনু থেকে **Pages** নির্বাচন করুন।
   - **Build and deployment** সেকশনে **Source** হিসেবে **`GitHub Actions`** নির্বাচন করুন।

3. কোড পুশ হওয়ার সাথে সাথে GitHub Actions স্বয়ংক্রিয়ভাবে টেস্ট চালাবে, প্রোডাকশন বিল্ড করবে এবং অ্যাপটি লাইভ করে দেবে।
4. কয়েক মিনিটের মধ্যে আপনি আপনার পাবলিক HTTPS লিঙ্ক পেয়ে যাবেন (যেমন: `https://<username>.github.io/<repo-name>/`)।

## 📲 অ্যান্ড্রয়েড ফোনে Google Chrome দিয়ে ইনস্টল করার নিয়ম (PWA Installation)

1. আপনার ফোনের **Google Chrome** ব্রাউজারে GitHub Pages-এর লিঙ্কটি খুলুন।
2. ব্রাউজারের ওপরের ডানদিকের **থ্রি-ডট (⋮) মেনু**-তে চাপ দিন।
3. **"Install app"** অথবা **"Add to Home screen"** (হোম স্ক্রিনে যোগ করুন) চাপুন।
4. কনফার্ম করলে অ্যাপটির আইকন আপনার ফোনের হোম স্ক্রিনে অ্যাপ আকারে যুক্ত হয়ে যাবে।
5. এরপর অ্যাপটি ওপেন করলে কোনো ব্রাউজার ফ্রেম বা অ্যাড্রেস বার ছাড়াই একদম নেটিভ অ্যাপের মতো ফুলস্ক্রিনে চলবে — এমনকি ইন্টারনেট বন্ধ থাকলেও!
